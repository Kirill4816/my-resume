Ml-проекты: анализ фрод операций и обнаружение болезней растений по фото

Репозиторрий содержит два проект по применению машинного обучения: 
выявление мошеннических операций по данным транзакций и
обнаружение заболеваний растений по изображениям.

Файл 1: Анализ мошеннических операций

Цель: построить модель классификации транзакций (фрод / не фрод) на основе данных с Kaggle 
Credit Card Fraud Detection c учетом сильного дизбаланса классов

Основные шаги:
1) Загрузка и первичный анализ данных, исследование распределений признаков и класса.
2) Предобработка: масштабирование, анализ мультиколлинеарности (VIF),
   обработка дисбаланса и разделение на train/test.
3) Обучение модели XGBoost с подбором гиперпараметров (Optuna / перекрестная проверка).

Результаты:
1) Достигнут высокий ROC AUC (около 0.99 на валидации) и приемлемый баланс precision/recall
  для редкого класса (мошенничество).
2) Построены метрики качества (confusion matrix, F1-score) и сделан вывод о пригодности модели
   для задач детекции фрода на уровне прототипа.


Файл 2: Выявление болезней растений по фото 

Цель: обучить бинарный классификатор (здоровое / больное) по изображениям
из датасета PlantVillage Kaggle

Основные шаги: 
1) Автоматическая загрузка датасета через Kaggle API, структурирование в
   бинарный датасет (healthy / diseased).
2) Подготовка данных: ресайз до 224×224, нормализация под ImageNet, разбиение
   на train/val (~80/20).
3) Использование предобученной ResNet18: заморозка базовых слоев, замена финального
   полносвязного слоя на 2 класса
